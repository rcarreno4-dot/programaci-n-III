## Estructura MVC

- `index.html`: estructura semántica y punto de entrada de la aplicación.
- `model/project-data.js`: información del proyecto, equipo, diagnóstico, propuesta y evidencias.
- `view/styles.css`: estilos visuales, diseño responsive y animaciones.
- `controller/app.js`: navegación entre pestañas y renderizado dinámico de cada vista.
- `assets/`: carpeta reservada para recursos locales del proyecto.

## Ejecución

Abre `index.html` con un servidor local para que los módulos JavaScript funcionen correctamente. En VS Code puedes usar Live Server o ejecutar cualquier servidor HTTP estático desde la carpeta `nom_cedula`.
