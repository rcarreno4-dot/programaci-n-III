# Frontend + Backend

Ejemplo académico que demuestra la integración organizada por capas de HTML, CSS y JavaScript, y explica las diferencias entre Frontend y Backend.

## Capas

- `index.html`: estructura semántica, contenido y accesibilidad.
- `css/styles.css`: colores, tipografía, distribución, responsive y estados visuales.
- `js/app.js`: filtro interactivo entre Frontend, Backend y todas las tecnologías.

## Ejecución

Abre `index.html` directamente en el navegador o utiliza un servidor local desde la carpeta `frontend-backend`.
