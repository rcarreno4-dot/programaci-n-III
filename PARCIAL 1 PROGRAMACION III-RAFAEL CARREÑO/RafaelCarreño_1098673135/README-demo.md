# Demo jugable

`views/demo.html` contiene el juego Neon Tap.

- El controlador `controllers/demo-controller.js` inicia y reinicia partidas.
- Cada clic en el objetivo aumenta la puntuación.
- Un temporizador de 20 segundos finaliza la partida.
- La posición del objetivo cambia con JavaScript.
- `css/pages.css` contiene la apariencia del tablero y el objetivo.
