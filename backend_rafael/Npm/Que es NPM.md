**NPM** (Node Package Manager) es el gestor de paquetes oficial de Node.js y 

el registro de software más grande del mundo para JavaScript.


Cumple dos funciones principales en el desarrollo de software:

Un Registro (Repositorio Online): Es una base de datos pública gigantesca donde 

desarrolladores de todo el mundo suben librerías, frameworks y herramientas de código abierto 

(como Express, React, Mongoose, nodemon, etc.) para que cualquiera pueda usarlas gratis.


Una Herramienta de Línea de Comandos (CLI): Es la utilidad que ejecutas en tu terminal para 

instalar, actualizar, configurar y gestionar las dependencias (librerías) de tus proyectos 

Node.js.


**Conceptos clave de NPM**


package.json: Es el archivo manifiesto que se crea en la raíz de tu proyecto. Guarda la 

metainformación del proyecto y la lista de paquetes instalados con sus versiones exactas.

node\_modules/: Es la carpeta que NPM crea automáticamente para almacenar el código fuente de 

todas las librerías que descargas.



**\*para que sirve un framework\***


Un framework (o marco de trabajo) sirve como una plantilla o estructura base prefabricada que te ayuda 

a construir aplicaciones de software de forma mucho más rápida, ordenada y segura.

En lugar de escribir todo el código desde cero (como gestionar peticiones HTTP, conectar la base de 

datos o validar usuarios), el framework te entrega esas herramientas listas para usar, definiendo 

reglas claras sobre cómo organizar tu proyecto.
